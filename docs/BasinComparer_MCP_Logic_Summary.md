# 盆地/凹陷勘探优先级评价与部署建议方案摘要（对标 SY/T 5519 盆地评价技术规范）

## 1. 方案目的

本方案拟建立一套面向石油勘探决策的盆地/凹陷综合评价机制，在已有综合地质报告、资源评价报告、钻井测试资料、地震解释成果等资料基础上，对多个盆地或凹陷进行统一口径的对比评价，形成勘探优先级排序和下一步工作部署建议。

方案重点解决以下问题：

- 哪些盆地或凹陷更值得优先投入勘探工作？
- 排序依据是否充分，主要差异体现在哪些地质条件上？
- 当前资料是否足以支撑排序和部署建议？
- 对于不同目标，下一步应部署预探井、评价井，还是先补充地震、测试、实验分析等资料？
- 哪些目标应暂缓钻探、降低优先级或转入专项研究？

本方案希望形成的不是单一分数，而是一套“资料基础判断、地质条件评价、优劣排序、风险说明、部署建议”相结合的决策支持结果。

## 2. 适用前提

本方案适用于相关目标已经具备一定资料基础的场景，包括但不限于：

- 盆地或凹陷综合地质评价报告。
- 烃源岩评价资料。
- 储层评价资料。
- 盖层、圈闭、成藏条件分析资料。
- 资源量或资源潜力评价资料。
- 钻井、录井、测井、测试及实验分析资料。
- 二维、三维地震解释及构造落实资料。

同时，`SY/T 5519-2011 盆地评价技术规范` 应作为评价标准依据纳入资料库，并能够在评价执行时被检索引用。后续资料完备性判断、评价内容覆盖检查、成果清单核查和专家复核问题，应以标准原文检索结果形成的对标清单为依据，而不是仅依赖方案摘要中的概括性表述。

如果某一目标关键资料明显不足，方案不应强行给出确定性排序，而应首先指出资料缺口及其对评价结论的影响。

## 3. 总体评价思路

建议采用以下工作逻辑：

```text
资料是否足够
    -> 地质条件是否有利
    -> 与其他目标相比优劣如何
    -> 风险和不确定性在哪里
    -> 下一步应采取什么勘探行动
```

其中，“资料是否足够”应作为前置判断。资料不足与地质条件差是两类不同问题，不能简单混为一个低分。

例如：

- 某凹陷烃源岩、储层、圈闭资料完整，评价结果显示条件较差，属于“地质条件风险较高”。
- 某凹陷资料缺失较多，无法判断储层或圈闭条件，属于“资料不足导致不能可靠评价”。

这两种情况对应的勘探建议应明显不同。

## 4. 标准符合性评价框架

本方案建议以 `SY/T 5519-2011 盆地评价技术规范` 作为当前对标基础，同时关注其后续修订方向。评价工作不宜只围绕单项地质条件打分，而应按照盆地评价的一般工作逻辑，形成从基础地质认识到勘探方向建议的完整链条。

实际执行时，应先检索标准原文，提取与本次任务相关的主要地质任务、评价原则、评价内容、评价步骤、评价方法和成果要求，形成标准对标清单。后续排序和部署建议应引用该清单进行约束和说明。

建议将标准符合性体现在以下几个方面：

| 标准化要求 | 本方案中的对应机制 | 专家评审重点 |
|---|---|---|
| 明确评价任务 | 以盆地/凹陷优选和勘探部署建议为核心任务 | 任务目标是否符合当前勘探阶段 |
| 坚持评价原则 | 先评价资料基础，再评价地质条件和资源潜力 | 是否避免资料不足导致误判 |
| 覆盖评价内容 | 基础地质、石油地质、资源潜力、勘探方向均纳入评价 | 评价内容是否完整 |
| 遵循评价步骤 | 资料检查、基础地质评价、成藏条件评价、资源潜力评价、有利区优选、部署建议 | 工作顺序是否符合盆地评价习惯 |
| 采用合理评价方法 | 定性判断、定量指标、专家校核相结合 | 指标、权重和判别标准是否合理 |
| 形成规定成果 | 排序结论、风险说明、资料缺口、部署建议、已有关键图件和表格引用清单 | 成果是否能支撑勘探决策 |

为保持与标准口径一致，建议把评价结果分为四个层次表达：

1. 基础地质条件认识。
2. 石油地质条件评价。
3. 油气资源潜力评价。
4. 有利区优选与勘探部署建议。

其中，盆地/凹陷排序应作为综合评价成果的一部分，而不是脱离基础地质和资源评价单独给出。

## 5. 对标 SY/T 5519 的评价内容与成果清单

结合盆地评价技术规范的工作要求，建议本方案至少覆盖以下评价内容和成果表达。

| 评价模块 | 主要评价内容 | 资料与证据要求 | 建议成果 |
|---|---|---|---|
| 基础地质条件评价 | 盆地成因与类型、地质结构与构造格架、沉积充填特征、盆地演化阶段 | 区域地质、构造解释、地层沉积、地震解释、综合研究资料 | 基础地质认识、构造单元划分、沉积演化认识 |
| 烃源条件评价 | 烃源岩分布、厚度、有机质丰度、成熟度、有机质类型、生烃强度 | 烃源岩实验分析、钻井资料、地化资料、成熟度资料 | 烃源条件评价结论、有效烃源区判断 |
| 储集条件评价 | 储层类型、展布、厚度、孔隙度、渗透率、非均质性、含油气性 | 岩心、录井、测井、测试、实验分析、储层预测资料 | 储层有利区、主要层系储集条件评价 |
| 封盖条件评价 | 盖层厚度、岩性、突破压力、连续性、保存条件 | 盖层分析、测井解释、实验数据、区域保存条件研究 | 封盖有效性评价、保存风险说明 |
| 圈闭与成藏组合评价 | 圈闭类型、规模、落实程度、形成时间、成藏期匹配、运移条件 | 构造解释、圈闭评价、油气显示、成藏研究资料 | 成藏组合评价、圈闭有效性判断 |
| 资源潜力评价 | 资源量、资源丰度、资源分布、可采性、资源评价可靠程度 | 资源评价报告、参数表、类比资料、资源量计算成果 | 资源潜力分级、资源分布认识 |
| 有利区与甜点区预测 | 有利区分布、重点区带、目标层系、甜点区预测 | 综合评价成果、储层预测、烃源条件、圈闭落实、资源分布 | 有利区划分、重点目标清单 |
| 勘探方向与部署建议 | 下一步勘探方向、井位论证、预探井/评价井部署、资料补充计划 | 综合评价结论、风险与不确定性说明、专家复核意见 | 勘探优先级排序、部署建议、资料补充建议 |

建议成果中还应明确关键图件和表格的引用及缺失情况，便于专家判断成果是否满足盆地评价要求。

本阶段不承担专业图件生成、地震解释、资源量重算或井位部署制图工作。关键图件原则上引用已有资料成果；对于缺失或不足的图件，只作为资料缺口和专家补充工作建议输出。

建议检查的图件包括：

- 盆地或凹陷构造单元划分图。
- 地层与沉积体系图。
- 烃源岩分布和成熟度图。
- 储层展布与有利储层预测图。
- 盖层分布与保存条件图。
- 圈闭分布与落实程度图。
- 成藏组合图。
- 资源潜力分布图。
- 有利区或甜点区预测图。
- 勘探部署建议图。

建议检查的表格包括：

- 参评目标基础资料清单。
- 关键评价指标表。
- 资料完备性评价表。
- 分维度评价结果表。
- 资源潜力对比表。
- 主要风险和资料缺口表。
- 勘探优先级排序表。
- 下一步部署建议表。

对于表格成果，本阶段以引用、核查和缺失识别为主。只有当资料中的表格已经具备可追溯的结构化行列数据时，才可生成引用式摘录表或对比汇总表；该类表格应明确标注来源，不应表述为重新计算或重新解释形成的专业成果表。

## 6. 资料完备性评价

资料完备性评价是正式排序前的必要环节，重点判断当前资料是否能够支撑综合地质评价和勘探部署决策。

建议从以下方面判断：

| 评价内容 | 关注问题 |
|---|---|
| 资料类型覆盖 | 是否具备综合地质、烃源岩、储层、盖层、圈闭、资源量、钻井测试、地震解释等资料 |
| 关键指标覆盖 | TOC、Ro、孔隙度、渗透率、盖层厚度、突破压力、圈闭规模、资源量等关键指标是否齐全 |
| 资料可靠性 | 指标是否来自正式报告、实测数据、表格数据或明确解释成果 |
| 资料一致性 | 不同报告或不同年份资料之间是否存在明显矛盾 |
| 资料时效性 | 是否存在新钻井、新地震、新测试资料未纳入评价 |
| 结论支撑程度 | 当前资料是否足以支撑排序、井位论证或钻井部署建议 |

建议将资料基础分为三类：

| 类型 | 含义 | 建议处理 |
|---|---|---|
| 资料较完整 | 关键维度和核心指标基本齐全 | 可进入正式排序和部署建议 |
| 资料部分完整 | 具备一定评价基础，但存在重要缺口 | 可进行初步排序，但需降低结论可信程度 |
| 资料不足 | 缺少关键维度或核心指标 | 不建议强行排序，应优先提出补充资料建议 |

## 7. 综合地质评价维度

建议初步采用五类核心评价维度。

| 维度 | 评价重点 |
|---|---|
| 烃源岩条件 | 有机质丰度、成熟度、有机质类型、生烃强度、有效烃源岩厚度 |
| 储层条件 | 孔隙度、渗透率、含油气性、储层厚度、储层连续性和非均质性 |
| 盖层条件 | 盖层厚度、封盖能力、突破压力、横向连续性和保存条件 |
| 圈闭条件 | 圈闭类型、规模、落实程度、形成时间与成藏期匹配关系 |
| 资源潜力 | 资源量、资源丰度、可采性、资源评价可靠程度 |

上述维度可根据专家意见进一步补充，例如运移条件、保存条件、工程条件、经济条件、交通与地面条件等。

## 8. 排序结果表达

建议排序结果不要只给出一个综合得分，而应同时说明排序依据和结论可信程度。

每个盆地或凹陷的排序结果建议包含：

- 综合排名。
- 主要优势。
- 主要短板。
- 关键地质风险。
- 关键资料缺口。
- 资料完备程度。
- 结论可信程度。
- 推荐的下一步行动。

这样可以避免出现“分数很精确，但不知道为什么排在前面”的问题，也便于专家复核排序逻辑。

## 9. 风险与不确定性区分

建议在评价中明确区分两类风险。

### 9.1 地质风险

指目标本身地质条件存在不利因素，例如：

- 烃源岩丰度或成熟度不足。
- 储层物性差。
- 盖层封闭能力不足。
- 圈闭落实程度低。
- 成藏期匹配关系不清。
- 资源规模或资源丰度偏低。

### 9.2 资料风险

指现有资料不足以支撑可靠判断，例如：

- 缺少关键层系储层物性数据。
- 缺少烃源岩实验分析数据。
- 圈闭规模或落实程度证据不足。
- 资源量估算依据不充分。
- 不同报告之间指标冲突。
- 关键资料年代较早，未反映最新勘探成果。

两类风险应分别说明。对于资料风险较高的目标，不能简单判定为地质条件差，应优先提出资料补充建议。

## 10. 勘探部署建议机制

排序结果最终应转化为勘探行动建议。建议采用“地质条件 + 资料完备程度 + 结论可信程度”的联合判断方式。

| 地质条件 | 资料基础 | 建议方向 |
|---|---|---|
| 较好 | 较完整 | 优先进入井位论证，可考虑部署预探井或评价井 |
| 较好 | 不充分 | 优先补齐关键资料，再决定是否进入钻井部署 |
| 中等 | 较完整 | 选择优势层系、构造带或区带开展专项评价 |
| 中等 | 不充分 | 补充储层、圈闭、资源量等关键证据后再排序 |
| 较差 | 较完整 | 暂缓钻探或降低投入优先级 |
| 较差 | 不充分 | 不给出强结论，重点列出资料缺口和风险 |

建议输出的行动类型包括：

- 优先部署预探井。
- 优先部署评价井。
- 进入井位论证。
- 补充二维或三维地震解释。
- 补充烃源岩、储层、盖层等实验分析。
- 开展重点区带或层系专项研究。
- 暂缓钻探。
- 降低勘探投入优先级。

## 11. 建议成果形式

建议最终成果采用专家易于审阅的报告形式，至少包括：

1. 结论摘要。
2. 参评盆地/凹陷清单。
3. 资料完备性评价。
4. 综合评价维度与评价依据。
5. 优先级排序结果。
6. 各目标主要优势、短板和风险。
7. 资料缺口及其对结论的影响。
8. 下一步勘探部署建议。
9. 已有图件和表格引用清单。
10. 缺失图件、缺失表格和缺失关键指标清单。
11. 需专家重点复核的问题清单。

其中，专家重点复核的问题可以包括：

- 评价维度是否完整。
- 关键指标是否符合行业评价习惯。
- 各维度权重是否合理。
- 资料完备性分级是否恰当。
- 勘探部署建议是否符合实际工作流程。
- 是否需要增加特定盆地或特定油气类型的评价规则。

## 12. 需要专家重点讨论的问题

为便于后续完善方案，建议请勘探专家重点评审以下问题：

1. 五类核心评价维度是否足以支撑盆地/凹陷优选。
2. 各维度在不同勘探阶段是否需要不同权重。
3. 哪些指标应作为“关键控制指标”，缺失时不应进入强排序。
4. 资料完备性如何分级更符合实际评价工作。
5. 高潜力但资料不足的目标，应如何在排序中体现。
6. 排序结果与井位部署建议之间应设置哪些约束条件。
7. 是否需要区分预探阶段、评价阶段、滚动勘探阶段的评价口径。

## 13. 初步结论

本方案建议将盆地/凹陷优选工作从单纯资料汇总或单项指标对比，提升为“资料基础评价 + 综合地质评价 + 优先级排序 + 勘探部署建议”的一体化机制。

其核心价值在于：

- 先判断资料是否足够，避免资料缺失导致误判。
- 统一评价维度，便于多个目标横向比较。
- 将排序结论与风险、不确定性、资料缺口一起表达。
- 将评价结果进一步转化为下一步勘探行动建议。

该方案后续应结合专家意见，对评价维度、关键指标、权重设置、资料完备性分级和部署建议规则进行细化。
