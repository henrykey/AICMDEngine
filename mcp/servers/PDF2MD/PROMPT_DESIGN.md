# 简洁提示词设计（支持双模式输出）

## 核心原则

**表格**：转Markdown表格 + 简单描述
**插图**：详细描述
**公式**：转LaTeX + 简单描述

**需要两套数据**：
- **Render数据**：用于可视化渲染（完整格式）
- **RAG数据**：用于语义检索（描述性）

---

## 提示词V1（简洁版）

```
将这页转为文字，生成两套数据：

【Render数据】用于渲染展示：
- 先识别页面类型（封面/目录/正文）
- 封面：保留标题、编号、日期
- 目录：保留章节名称和层次，去掉页码
- 正文：去掉页眉页脚页码
  * 文字正常识别
  * 表格转为Markdown表格
  * 插图用详细描述占位
  * 公式转LaTeX格式

【RAG数据】用于语义检索：
- 表格：简单描述内容
- 插图：详细描述
- 公式：简单描述含义

最后输出JSON：
{
  "render": "渲染用的完整内容（Markdown格式）",
  "rag": "检索用的文字描述（纯文本）"
}
```

---

## 提示词V2（更简洁）

```
分析这页PDF，生成Render和RAG两套数据。

【Render】- 用于展示：
- 识别页面类型（封面/目录/正文）
- 封面保留标题编号日期；目录保留章节去掉页码
- 正文：去页眉页脚页码，文字正常识别，表格转Markdown，插图详细描述占位，公式转LaTeX

【RAG】- 用于检索：
- 表格简单描述
- 插图详细描述
- 公式简单描述

输出JSON：{"render": "Markdown内容", "rag": "文字描述"}
```

---

## 提示词V3（最简洁）

```
将这页PDF转为Render和RAG两套数据。

Render（展示用）：
- 识别类型（封面/目录/正文）
- 封面留标题日期；目录留章节去页码
- 正文：去页眉页脚页码，表格→Markdown，插图→详细描述，公式→LaTeX

RAG（检索用）：
- 表格简单描述，插图详细描述，公式简单描述

输出JSON：{"render": "...", "rag": "..."}
```

---

## 说明

三个版本的对比：

| 版本 | 长度 | 特点 |
|------|------|------|
| V1 | 中等 | 结构化说明，清晰分工 |
| V2 | 简洁 | 流程化，重点突出 |
| V3 | 极简 | 最短，依赖模型理解力 |

**推荐使用V2**，在简洁和清晰之间取得平衡。

关键改进：
1. **明确双模式** - Render和RAG
2. **分工明确** - Render用于展示（格式完整），RAG用于检索（语义描述）
3. **简洁原则** - 不过度解释，信任模型
4. **JSON输出** - 便于程序处理
